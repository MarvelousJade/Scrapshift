Character and item appearance rules

Matching rules: attachment positions, display priority, latest equal-priority replacement, duplicate suppression, layers behind the body, skin-slot priority, and removal without restoring an overwritten appearance. Original wearable sprites are fitted to Scrapshift’s body proportions; UI item icons keep their separate artwork.

The hide-appearance setting follows source acquisition behavior: it suppresses new wearable additions while enabled and keeps character features. It does not erase world layers already acquired. Portraits filter item layers using the current setting.
