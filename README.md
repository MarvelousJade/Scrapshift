# Scrapshift

A small Unity arena-survival game: pilot a repair robot, recover scrap, and survive five one-minute waves aboard a damaged ship. Original geometric robot art, automatic weapons, and a limited set of upgrades keep the project focused.

## Why this exists

The target Unity Editor role asks for C#, experience building Unity projects, automated testing, and attention to creators' workflows. AssetScope is the companion Editor tool. Scrapshift supplies a real playable project whose materials, prefabs, meshes, and data assets can be inspected with it.

Brotato is the gameplay reference for movement, auto-attacks and between-wave decisions. This project uses its own code, title, art and audio. It does not aim to reproduce Brotato's content, balance or complete feature set.

## Development

Unity **6000.6.5f1**, Windows. Open this directory as a Unity project. Initial content is generated by **Scrapshift > Generate Game Content**, then open `Assets/Scrapshift/Content/Scenes/Deck.unity`.

Controls: WASD or arrow keys to move; Escape pauses; 1/2/3 selects upgrades; M toggles sound; Enter starts or restarts. Mouse buttons also work on menus.

Playable Windows output: `Builds/Windows/Scrapshift.exe`. Keep the entire Windows folder together. The packaged download is `Builds/Scrapshift-Windows.zip`.

To verify or rebuild, run `./scripts/verify.ps1` and `./scripts/build.ps1` with the game project's Editor closed. Build binaries and raw logs are intentionally excluded from Git; source, Unity `.meta` files, test summaries and selected screenshots are tracked.
